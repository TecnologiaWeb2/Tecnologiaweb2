# KICKOFF · Mensaje para pedir la entrevista

> Plantilla para validar el sistema con una asociación real (el proyecto usa un caso verosímil declarado en [BRIEF.md](BRIEF.md)).

**Asunto:** Proyecto universitario gratuito para la asociación — UPDS, Tecnología Web II

Buenas tardes, señora presidenta:

Somos estudiantes de Ingeniería de Sistemas de la UPDS (Santa Cruz). En la materia Tecnología Web II desarrollamos,
sin costo, un sistema web para una asociación de productores. Nos gustaría conversar 30 minutos con usted o con quien
lleve las ventas para entender cómo registran las entregas de las socias, los pagos y los pedidos de las tiendas.

- **No pediremos contraseñas, cuentas bancarias ni accesos** a ningún sistema de la asociación.
- Los datos de prueba serán inventados; si usamos datos reales de socias, será solo con su permiso por escrito.
- Al final entregaremos el sistema publicado, un manual de uso y una demostración.

Podemos ir a la sede o hacerlo por videollamada, en el horario que les quede mejor.

Atentamente,
Daniela Cayo Mamani · Juan José Vicente Cossio · Ronald Salvatierra Flores · Yordy Tolavi Ruiz · Alejandro Cadario Lopez
Docente: M.Sc. Ing. Jimmy Nataniel Requena Llorentty

## Guion de la entrevista (30 min)

1. ¿Cómo reciben las prendas de las socias? ¿Quién las revisa y qué pasa con las que tienen fallas?
2. ¿Cómo y cuándo les pagan? ¿Hubo reclamos? ¿Cuántos en el último trimestre?
3. ¿Quiénes les compran por encargo? ¿Les pasó no poder entregar un pedido completo?
4. ¿Qué informes presentan a la asamblea? ¿Cuánto tardan en armarlos?
5. ¿Quién usaría el sistema y desde qué equipo (celular, computadora)?
